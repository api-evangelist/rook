The Rook v1.12 release is out! v1.12 is another feature-filled release to improve storage for Kubernetes. Thanks again to the community for all the great support in this journey to deploy storage in production. The statistics continue to show Rook community growth since the v1.11 release in February: 10.8K to 11.1K Github stars 278M to 288M Container downloads 5.8K to 6.1K Slack members 7.0K to 7.1K Twitter followers We have a lot of new features for the Ceph storage provider that we hope you’ll be excited about with the v1.12 release !
