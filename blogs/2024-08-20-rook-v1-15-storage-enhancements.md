The Rook v1.15 release is out! v1.15 is another feature-filled release to improve storage for Kubernetes. Thanks again to the community for all the great support in this journey to deploy storage in production. The statistics continue to show Rook community growth since the v1.14 release in April: 11.9K to 12.2K Github stars 317M to 333M Container downloads 6.6K to 6.8K Slack members 7.5K to 7.7K X followers We have a lot of new features for the Ceph storage provider that we hope you’ll be excited about with the v1.15 release !
