The Rook v1.16 release is out! v1.16 is another feature-filled release to improve storage for Kubernetes. Thanks again to the community for all the great support in this journey to deploy storage in production. The statistics continue to show Rook community growth since the v1.15 release in August: 12.2K to 12.5K Github stars 333M to 337M Container downloads 6.8K to 7.1K Slack members 7.7K to 7.9K X followers We have a lot of new features for the Ceph storage provider that we hope you’ll be excited about with the v1.16 release !
