The Rook v1.13 release is out! v1.13 is another feature-filled release to improve storage for Kubernetes. Thanks again to the community for all the great support in this journey to deploy storage in production. The statistics continue to show Rook community growth since the v1.12 release in July: 11.1K to 11.6K Github stars 288M to 304M Container downloads 6.1K to 6.4K Slack members 7.1K to 7.3K X followers We have a lot of new features for the Ceph storage provider that we hope you’ll be excited about with the v1.13 release !
